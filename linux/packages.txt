#
# Scope: apt owns ONLY the base system. Every language runtime and dev CLI comes
# from mise (dotfiles/mise/config.toml), which is already cross-platform. Do not
# duplicate anything mise manages — node, go, python, kubectl, terraform, gh,
# ripgrep, fd, bat, fzf, jq, yq, neovim, shellcheck, ... Listing them here just
# shadows mise's shims with older Debian builds and makes upgrades ambiguous.
#
# Format: one package per line. '#' comments and blank lines are ignored.
# Consumed by macos/restore.sh -> install_packages().
# Inventory the live system with:  apt-mark showmanual

# === Agent sandboxing — REQUIRED, not optional ===
# Claude Code's Linux sandbox is bubblewrap + socat, and Codex's is bubblewrap.
# linux/claude-settings.json sets failIfUnavailable=true, which means a missing
# bwrap is a hard startup failure rather than a silent fall back to running
# model-generated commands unsandboxed. Removing these does not soften the
# posture — it stops Claude Code from running at all. That is the intent.
bubblewrap
socat

# === Server observability ===
# dotfiles/mise/config.toml notes these two have no macOS aqua binaries and are
# "kept in brew on Mac" — but no mise entry exists for them, so on Linux apt is
# the one thing that actually provides them.
btop
ncdu

# === Containers — for your shell and CI, NOT for agents ===
# Rootless podman provides the Docker-compatible API socket testcontainers-go looks
# for. It is deliberately unreachable from inside an agent sandbox, and that is not
# an oversight to be fixed later: Claude Code blocks AF_UNIX with a seccomp filter,
# and seccomp cannot allow a single socket by path — `allowUnixSockets` says
# "macOS only ... ignored on Linux" in its own schema. The only switch that works
# here is `allowAllUnixSockets`, which also exposes the forwarded SSH agent and
# would let an agent sign and push with no Touch ID tap. Read linux/sandbox.md
# before changing this.
#
# The trade costs little: 28 of 746 test files in the go monorepo need containers,
# and they already sit behind //go:build e2e|integration tags that a plain
# `go test ./...` skips. Agents run the other ~96% inside the sandbox.
podman
uidmap         # newuidmap/newgidmap — rootless podman cannot map subuids without it
passt          # pasta: podman 5's default rootless network backend
